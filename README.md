# Fuel Prices

Automated AIP fuel price extracts for Diesel and ULP.

## Files

- `data/AIP_fuel_prices_formatted.xlsx`
- `data/AIP_diesel_prices.csv`
- `data/AIP_ulp_prices.csv`
- `documentation/AIP_fuel_price_pipeline_documentation.Rmd`

The CSV files are intended for Power BI connection using raw GitHub URLs.
